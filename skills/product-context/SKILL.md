# Product context

## Purpose

Preserve “A pele tem memória”, Método REEDUCA and the support role of software.

## When to use

Requirements, UX copy, workflows, AI behavior or prioritization.

## When not to use

Pure tooling changes with no user/product effect.

## Inputs

Proposal, user outcome, copy/acceptance criteria.

## Process

Compare with `docs/product`; separate evidence from assumption; flag new claims/scope; escalate medical or brand ambiguity.

## Checklist

- Routine/photo/evolution alignment
- No diagnosis, cure or invented claim
- Out-of-scope explicit
- User value and acceptance criteria clear

## Expected output

Approved scope or concise conflicts/questions.
