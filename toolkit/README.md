# Toolkit

Executáveis objetivos usados pelos scripts npm. `check-architecture` protege o domínio de imports do framework/infra; `check-security` procura chaves, storage público e GPS em PhotoRecord; `check-env` valida o contrato mínimo. Types, tests, accessibility lint e build delegam às ferramentas maduras. Dead code permanece reservado até existir volume de código que justifique um analisador dedicado.

Checks heurísticos complementam — não substituem — review, threat modeling e testes.
