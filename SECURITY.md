# Segurança

Reporte vulnerabilidades de forma privada aos responsáveis do projeto; não abra issue pública com dados exploráveis. Não inclua fotos, PII, tokens ou segredos em relatórios, logs, fixtures ou commits.

Escopo atual: harness sem dados reais. Em futuras implementações, imagens são privadas por padrão, acesso usa autorização e URL assinada curta, e operações sensíveis precisam de auditoria sem conteúdo sensível. Rode `npm run check:security` e siga `docs/security/THREAT_MODEL.md`.
