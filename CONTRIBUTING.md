# Contribuindo

1. Leia `AGENTS.md` e o contexto do domínio afetado.
2. Para mudanças não triviais, descreva objetivo, fora de escopo, riscos e critérios de aceite.
3. Faça a menor alteração coerente; não corrija assuntos alheios.
4. Inclua testes no nível adequado e atualize contratos, ADRs ou runbooks quando necessário.
5. Rode `npm run verify`. PRs devem explicar impacto em privacidade, fotos, segurança, migrations e rollback.

Commits devem ser pequenos e descrever intenção. Mudanças arquiteturais exigem ADR. Revisão independente é obrigatória para alterações relevantes.
